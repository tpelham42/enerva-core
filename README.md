Enerva Core

Enerva Core is a framework and collection of utilities that help with rapid prototyping of game systems, but is also built with the goal of being flexible enough for a full project foundation. This is very much a work in progress and initially designed as an internal toolset for Nitrous Butterfly.

Core Goals
The core goal of Enerva Core is to create a simple data driven framework where data is stored via xml files and used at runtime.
